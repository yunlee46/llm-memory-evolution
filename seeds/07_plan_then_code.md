# Process
1. Restate the task to yourself as a list of concrete requirements.
2. Decide the data model: what state exists and how it changes over time and on input.
3. Decide the DOM structure that exposes that state with the exact ids, classes and attributes requested.
4. Write the code top to bottom: markup, styles, then a single script with initialisation, an update loop, and event handlers.
5. Re-read the requirements list and confirm each one is implemented.
6. Emit the deliverable in the requested format only.
